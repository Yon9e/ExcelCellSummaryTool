# FADT Penpot RAW A+C 重构设计

**日期：** 2026-07-27  
**状态：** 已确认  
**范围：** 自托管 Penpot 中 `FADT UI Baseline` 文件的 `RAW` 页面  
**依据：** GitHub Release v0.2.8、`FADT Dashboard Baseline` 页面、用户确认的 A+C 方向

## 目标

将现有 RAW 从“机械堆叠的深色表单”重构为具有明确层级、统一节奏和审计专业感的桌面工作台：

1. 主页面采用方案 A：忠实继承 Dashboard Baseline 的侧栏、顶栏、标题、标签和内容卡结构。
2. 高密度页面采用方案 C：窄图标导航、上下文导航和大面积任务工作区。
3. 保留 Release v0.2.8 的全部功能含义，不新增虚构功能或初始化数据。
4. 增加克制的多色语义系统，让组件、图标、数字、标题和状态更易区分。
5. 所有画板保持 1440×900；复杂工作页提供明确的返回入口。

## 视觉方向

### 核心语言

视觉关键词为“审计工作台、清晰、紧凑、可信”。页面不使用大面积纯黑，不采用发光霓虹或过多渐变。颜色用于表达功能和状态，而不是装饰性铺满。

标志性元素为左侧活动轨：当前模块使用紫色背景、青色细轨和对应图标形成稳定定位；高密度工作页沿用该轨道，但收窄为图标栏，为表格和预览区释放空间。

### 色彩系统

| 用途 | 色值 | 应用 |
|---|---|---|
| 应用背景 | `#242031` | 主画布 |
| 侧栏背景 | `#2E283A` | 一级导航、上下文导航 |
| 卡片背景 | `#332D3F` | 内容卡、统计卡 |
| 输入背景 | `#25202F` | 输入框、表格深色单元格 |
| 边框 | `#463E51` | 卡片、输入框、分隔线 |
| 主紫 | `#7C3AED` | 主操作、当前模块、品牌 |
| 深紫 | `#5B2CCB` | 激活标签、按下状态 |
| 信息蓝 | `#0EA5E9` | 文件、OCR、帮助、信息状态 |
| 辅助青 | `#06B6D4` | 当前步骤、焦点、处理状态 |
| 成功绿 | `#10B981` | 完成、有效、成功日志 |
| 警告橙 | `#F59E0B` | 重复项、等待确认、注意事项 |
| 危险红 | `#EF4444` | 删除、错误、失败日志 |
| 主文字 | `#F4F1F8` | 标题、输入内容 |
| 次文字 | `#B7AFC0` | 标签、说明 |
| 弱文字 | `#81788E` | 占位符、禁用信息 |

多色规则：

- 同一容器最多使用一个主强调色和一个状态色。
- 正文保持中性色；栏目标题、统计数字、图标、徽标可使用语义色。
- 主按钮使用紫色，信息操作使用蓝色，完成操作使用绿色，危险操作使用红色。
- 不以颜色作为唯一信息载体，同时保留图标、文本或状态标签。

### 字体

- 中文：`Noto Sans SC`。
- 英文、数字与版本号：`Inter Tight`。
- 页面标题 28–32 px，模块标题 20–24 px，卡片标题 16–18 px。
- 正文、表格与控件以 13–14 px 为主；辅助信息 12 px。
- 仅标题、统计数字和关键状态使用强调色；输入文本不做彩色化。

### 图标

统一使用简洁线性图标，禁止混用 Emoji、填充图标和不同笔画体系。

- 一级导航：汇总、OCR、文本清洗、关于。
- 操作：新增、打开、保存、选择、运行、复制、删除、返回、帮助。
- 状态：成功、警告、失败、等待、文件、文件夹。
- 图标必须与文字并列；仅在窄导航栏中允许纯图标，并提供明确的激活状态。

## 布局系统

### A 型：主页面

- 左侧完整导航栏：216 px。
- 顶部状态栏：48–56 px。
- 页面内容区左右安全边距：24 px。
- 页面头部包含眉题、标题、简短说明和右侧主操作。
- 汇总模块内部标签保持横向排列。
- 内容使用 1–3 张大卡片组织，不把每个字段单独包成卡片。
- 默认空状态放在主要工作区中央，包含图标、说明和单一行动入口。

### C 型：高密度工作页

- 左侧图标栏：64–72 px。
- 可选上下文导航：184–216 px。
- 主工作区占据剩余空间，表格、图片预览和候选规则优先。
- 顶部始终提供返回、页面标题、上下文说明和必要操作。
- 信息区和操作区通过固定工具栏或清晰分栏组织。
- 禁止在 1440×900 内把内容等比缩小到难以阅读；必要时使用滚动、分页或可折叠辅助区。

## 组件规范

- 按钮高度 36–40 px；主按钮、次按钮、危险按钮层级明确。
- 输入框高度 38–40 px；标签位于控件上方，不使用过大的内边距。
- 卡片圆角 10–12 px；按钮和输入框圆角 7–8 px。
- 表格行高 42–48 px；复选框、拖动手柄和行内操作保留安全间距。
- 状态徽标使用浅色文字、低透明背景和细边框。
- 空状态、提示条和日志等级分别使用信息蓝、警告橙、成功绿、危险红。
- 图标尺寸 16–20 px，一级导航图标 20–22 px。

## 内容与初始化

- 所有主页面保持 Release v0.2.8 首次启动状态：方案、文件、规则、日志、OCR 内容和文本清洗内容均为空。
- 不展示虚构公司名、文件路径、金额、处理数量或任务进度。
- 可以使用结构性占位文本，例如“尚未选择数据源”“暂无规则”“等待开始任务”。
- 建议改版批注放在画板外或固定批注区，不混入产品界面。

## Penpot 实施边界

- 仅覆盖 `RAW` 页面；`FADT Dashboard Baseline` 页面和共享库不修改。
- 文字必须保持可编辑文本，不转为图片。
- 图标优先使用 Penpot 可编辑矢量或统一字符图标，不嵌入截图。
- 画板名称、顺序和 1440×900 尺寸保持稳定。
- 允许重新组合组件和信息层级，但不得删除 Release v0.2.8 已存在的功能入口。

## 验收标准

1. 13 个画板全部存在、顺序正确且均为 1440×900。
2. 主页面可明显识别为 Dashboard Baseline 的同一设计系统。
3. 高密度页面在 1440×900 下仍保持 13 px 以上核心文字和清晰的返回入口。
4. 每页主操作不超过一个强主按钮；危险操作不与主操作同色。
5. 组件、图标、字体颜色使用语义色，但页面整体不显杂乱。
6. 所有业务文字均为可编辑文本，初始化内容为空。
7. `FADT Dashboard Baseline` 页面不发生任何变化。
