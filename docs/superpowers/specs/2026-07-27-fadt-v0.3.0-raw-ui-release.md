# FADT v0.3.0 RAW UI Release 设计规格

**日期：** 2026-07-27  
**产品：** FADT · Financial Audit Data Toolkit  
**设计依据：** 自托管 Penpot `FADT UI Baseline / RAW`、`FADT Dashboard Baseline`、Release v0.2.8  
**目标版本：** v0.3.0

## 1. 目标

将 FADT v0.2.8 的完整业务能力迁移到 Penpot RAW 已确认的 A+C 审计工作台视觉体系，并新增“设置”页管理动效模式。改造不得改变 Rust 命令、Excel 汇总、OCR、混合数据源选择、方案迁移和用户数据兼容语义。

## 2. 不变约束

- 桌面技术栈保持 Tauri 2 + Vue 3 + TypeScript + Pinia + Rust。
- 应用标识 `com.yon9e.excel-cell-summary-tool` 保持不变。
- `%APPDATA%\FADT` 与 `%LOCALAPPDATA%\FADT` 用户数据继续使用；旧版迁移继续保留。
- 混合数据源选择器仍支持同页多选 Excel 文件和文件夹；双击文件夹只负责进入内部。
- OCR 表格坐标和目标数据只读；只有输出列名文本可在确认后修正。
- 新安装和新建方案为空；升级用户继续载入已有方案和 OCR 设置。
- 浏览器只验证布局和纯前端交互；本机能力必须在 Tauri portable 中复验。

## 5. 设置页

设置页首期只包含“界面动效”：

- 自动：根据系统减少动态效果和真实渲染性能选择完整或精简。
- 完整：启用页面进入、卡片错峰、控件反馈和拖动让位动画。
- 精简：关闭非必要动画，保留状态反馈、进度和拖动位置变化。
- 当前判断结果：显示“完整效果”或“已降级”，并显示触发原因。
- 恢复默认：切回自动模式。

设置写入本地 `localStorage`，不进入方案文件，不上传，不新增 Rust 命令。

## 6. 性能判断

- `prefers-reduced-motion: reduce` 直接使用精简模式。
- 启动后和主要页面切换期间通过 `requestAnimationFrame` 采样。
- 平均帧间隔超过 22ms、卡顿帧占比超过 20%，或检测到连续长任务时判定为低性能。
- 自动模式一旦在本次运行降级，不自动恢复，避免动效状态来回切换。
- 用户选择完整或精简时覆盖自动判断。

## 7. 动效

- 页面进入：220ms 淡入和 8px 位移。
- 卡片错峰：单项间隔不超过 30ms，总时长不超过 320ms。
- 控件悬停与按下：120–160ms。
- 拖动：跟手预览与 160ms 让位动画。
- 进度和 OCR：只在运行期间显示动态状态。
- 禁止持续背景动画、滚动劫持和影响输入焦点的动画。

## 8. 响应式

- `≥1280px`：完整 A 型侧栏和 RAW 原布局。
- `1000–1279px`：侧栏压缩为图标模式，主内容保持可读双栏。
- `900–999px`：卡片改为单栏；表格在自身容器内横向滚动。
- C 型页面优先压缩上下文导航，不缩放核心工作区。
- Tauri 最小窗口继续为 900×620。

## 9. 无障碍

- 正文、按钮、输入框达到 WCAG AA 对比度。
- 状态同时使用颜色、图标和文字。
- 所有可交互控件具有清晰 `:focus-visible`。
- 主导航、标签、设置选项和返回操作支持键盘。
- 动效遵循系统减少动态效果设置。

- 14 个页面在 1440×900、1280×820 和 900×620 无关键重叠或裁切。
- 现有 Vitest、类型检查、前端构建、Rust fmt、Clippy 和 Cargo 测试全部通过。
- 数据源选择、规则拖动、OCR 设置、图片规则、Sheet 冲突、手册返回和设置持久化完成桌面冒烟。
- portable、安装包、发布审计和 SHA256 通过。
- 推送 GitHub 并创建 v0.3.0 Release。
