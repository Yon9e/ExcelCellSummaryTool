# FADT v0.3.0 Design QA

## Scope

- Penpot reference: `FADT UI Baseline / RAW`
- Implementation: Vue/Tauri frontend at `http://127.0.0.1:5173/`
- Primary viewport: 1440 × 900
- Minimum supported viewport: 900 × 620

## Visual comparison

- Compared the Penpot settings board and the running implementation in one visual input.
- The implementation preserves the RAW visual language: dark plum surfaces, purple primary state, cyan focus/accent, green status, amber performance guidance, compact icon navigation, and high-density cards.
- Copy and runtime status differ intentionally because the implementation reports live motion sampling and session degradation.

## Responsive checks

- 1440 × 900: full sidebar, stable content padding, three motion-mode cards, two status cards.
- 900 × 620: 64 px icon sidebar, 836 px main region, single-column card flow, internal vertical scrolling.
- The apparent blank area in one captured image was isolated to the browser screenshot viewport override; DOM geometry confirmed the application root consumes the full 900 px viewport.

## Interaction and accessibility checks

- Settings navigation is keyboard-addressable and exposes an active state.
- Motion modes expose `aria-pressed`; switching to “完整” and restoring “自动” were verified.
- Focus indicators remain visible and status is communicated through text in addition to color.
- No browser console warnings or errors were recorded.
- Automatic motion degradation remains session-sticky while explicit user selection takes precedence.

## Result

final result: passed
