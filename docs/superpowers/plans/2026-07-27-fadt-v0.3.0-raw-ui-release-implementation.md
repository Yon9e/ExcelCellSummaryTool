# FADT v0.3.0 RAW UI Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 FADT v0.2.8 完整迁移到 Penpot RAW A+C 视觉体系，新增可持久化和自动降级的动效设置，并交付 v0.3.0 portable、安装包与 GitHub Release。

**Architecture:** 保留 `App.vue` 作为汇总业务编排入口，把品牌侧栏、顶栏、页面眉题、设置页和高密度外壳拆成小组件；旧 CSS 保留复杂交互基础，新增以 `.fadt-v3` 为根的令牌和覆盖层，逐页替换外观而不重写 Rust 业务。动效判断使用纯函数和 Pinia 设置 Store，浏览器端采样，用户覆盖优先于自动判断。

**Tech Stack:** Tauri 2、Vue 3、TypeScript、Pinia、Vitest、Vue Test Utils、Lucide Vue、CSS、Rust、Penpot MCP、GitHub CLI

## Global Constraints

- 目标版本必须统一为 `0.3.0`。
- 最小窗口保持 `900×620`；设计基准为 `1440×900`。
- 不修改应用标识 `com.yon9e.excel-cell-summary-tool`。
- 不修改 Rust command 名称、参数或返回类型。
- 不清空或覆盖 `%APPDATA%\FADT`、`%LOCALAPPDATA%\FADT` 和旧版迁移数据。
- 新安装和新建方案默认无方案、无数据源、无规则、无日志和无 OCR 内容。
- 数据源混选、双击文件夹导航、递归扫描、重复预检语义保持不变。
- OCR 坐标和目标数据只读；只有输出列名文本可在确认后修改。
- UI 图标继续使用已安装的 Lucide Vue，不使用 Emoji、CSS 图标或图片化业务文字。
- 所有新增行为必须遵循测试先行。

- [ ] **Step 3: 实现纯函数**

```typescript
export type MotionMode = "auto" | "full" | "reduced";
export type MotionLevel = "full" | "reduced";

export function evaluateFramePerformance(intervals: number[]) {
  const average = intervals.reduce((sum, value) => sum + value, 0) / Math.max(intervals.length, 1);
  const droppedRatio = intervals.filter(value => value > 34).length / Math.max(intervals.length, 1);
  return average > 22 || droppedRatio > 0.2
    ? { degraded: true, reason: "检测到渲染卡顿" }
    : { degraded: false, reason: "渲染性能正常" };
}
```

`resolveMotionLevel()` 按“用户精简 > 用户完整 > 系统减少动态效果 > 会话性能降级 > 完整”顺序解析。
