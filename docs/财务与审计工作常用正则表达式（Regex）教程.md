# 财务与审计工作常用正则表达式（Regex）教程

本教程与 FADT 的“文本清洗 > 自定义正则”配套。工具使用 JavaScript 正则语法：捕获组在替换内容中写作 `$1`、`$2`；常用标记为 `g`（全部）、`m`（多行）、`i`（忽略大小写）。

## 空格与换行

| 场景 | 查找 | 替换 | 标记 |
| --- | --- | --- | --- |
| 去除每行首尾空格 | `^\s+|\s+$` | 留空 | `gm` |
| 多个空格合并为一个 | `[ \t]+` | 一个半角空格 | `g` |
| 删除空行 | `^\s*\r?\n` | 留空 | `gm` |
| 多个空行合并为一个 | `(\r?\n){3,}` | `\n\n` | `g` |
| 特殊空格转普通空格 | `[\u00A0\u3000]` | 一个半角空格 | `g` |

## 公司与单位名称

| 场景 | 查找 | 替换 |
| --- | --- | --- |
| 删除括号内简称 | `（.*?）|\(.*?\)` | 留空 |
| 删除结尾公司后缀 | `(?:股份)?有限公司$` | 留空 |
| 提取“单位名称”字段 | `^单位名称[：:]\s*(.+)$` | `$1` |

## 日期与期间

| 场景 | 查找 | 替换 |
| --- | --- | --- |
| `20301231` 转 `2030-12-31` | `^(\d{4})(\d{2})(\d{2})$` | `$1-$2-$3` |
| 中文日期转横线日期 | `(\d{4})年(\d{1,2})月(\d{1,2})日` | `$1-$2-$3` |

正则只能判断格式，不能确认 `2030-99-99` 是否为有效日期。

## 金额与百分比

| 场景 | 查找 | 替换 |
| --- | --- | --- |
| 删除货币符号和千分位 | `[￥¥,]` | 留空 |
| 括号负数转负号 | `^\((.+)\)$` | `-$1` |
| 整行提取带正负号金额 | `^.*?([+-]?\d+(?:\.\d+)?).*$` | `$1` |
| 整行提取百分比数值 | `^.*?([+-]?\d+(?:\.\d+)?)%.*$` | `$1` |

正则不负责金额乘除、汇率换算或合计。

## 科目、账号与编号

| 场景 | 查找 | 替换 |
| --- | --- | --- |
| 删除科目编码 | `^\d+\s*` | 留空 |
| 末级科目 | `^.*[\\/]` | 留空 |
| 删除账号空格和横线 | `[\s-]+` | 留空 |
| 账号脱敏 | `^(\d{4})\d+(\d{4})$` | `$1********$2` |
| 提取编号标签后的内容 | `^(?:合同编号|凭证号|发票号码)[：:]\s*(.+)$` | `$1` |

账号、发票号、凭证号和含前导零的编码应按文本保存，可同时启用“添加前置撇号”。

## OCR 结果清洗

| 场景 | 查找 | 替换 |
| --- | --- | --- |
| 删除汉字之间空格 | `(?<=[\u4e00-\u9fff])\s+(?=[\u4e00-\u9fff])` | 留空 |
| 合并数字之间空格 | `(?<=\d)\s+(?=\d)` | 留空 |
| 删除页码文字 | `第\s*\d+\s*页` | 留空 |
| 统一英文冒号为中文冒号 | `:` | `：` |

## 捕获组与重组

圆括号 `()` 捕获需要保留的内容，替换时按顺序使用 `$1`、`$2`、`$3`。替换内容支持 `\t`（制表符）、`\n`（换行）和 `\r`（回车）。

```text
查找：^(\d{4})(\d{2})(\d{2})$
替换：$1-$2-$3
```

非捕获组 `(?:...)` 只用于组合，不占用捕获组编号。懒惰匹配 `.*?` 通常比 `.*` 更适合删除多组括号内容。

## 使用边界与安全

1. 先在少量内容中查看右侧实时预览，再复制完整结果。
2. `^` 和 `$` 分别表示开头与结尾；处理多行文本时启用 `m`。
3. `g` 表示替换全部匹配；未启用时只替换第一个匹配。
4. 正则适合查找、提取、删除和重组，不适合计算或验证业务真实性。
5. 对正式底稿和原始清单操作前保留备份，并核对匹配数量和替换结果。
